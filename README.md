# Project Navigation

A simple **multi page website** built using **HTML and CSS**. The website contains multiple pages connected through a common navigation bar.

## ✨ Features

- Home page
- About page
- Projects page
- Achievements page
- Contact page
- Common navigation across all pages
- Active page navigation styling
- Full-screen gradient backgrounds
- Hover effects on navigation links
- Clean and simple layout

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Gradients

## 📁 Project Structure

```text
Project-6/
├── Project_6.html
├── home.html
├── about.html
├── project.html
├── acheivment.html
├── contact.html
└── style.css
```

## 🎨 Design

Each page has its own gradient background while sharing the same navigation design. The navigation uses Flexbox and includes hover and active-page effects.


## 📌 Purpose

This project demonstrates the basics of creating a **multi-page website**, linking HTML pages together, and applying consistent CSS styling across the website.
